# Markroom v0.1.0: early source preview

Status: unreleased. These notes describe the prepared first source release.

Markroom gives a small group one shared room for reviewing a PDF. Upload a document, share its room link, annotate and discuss it, then freeze the review and download a copy with editable PDF comments. The original file remains unchanged.

## Included

- A self-hosted EmbedPDF/PDFium viewer with highlights, notes, free text, shapes, ink, links, and threaded replies.
- Browser-held edit permissions: reviewers control their own annotations and the owner can close the review.
- Explicit **Check for updates** synchronization with revision-conflict handling.
- Editable PDF export that preserves comments and replies and stops when synchronization or saves fail.
- Local setup and one documented Cloudflare Workers/D1/R2 deployment path.
- A [two-page synthetic sample PDF](../../examples/markroom-sample.pdf), a [workspace screenshot](../images/markroom-review.png), and a [two-browser acceptance check](../../README.md#two-browser-acceptance-check).

## Reliability work in this preview

Closing a review preserves saved annotations. Malformed records are isolated, deleted comment contents are scrubbed, closed-room writes are rejected, and uploads are bounded using their actual byte count. The npm lockfile includes the optional dependencies required by clean Linux installs.

GitHub CI checks locked installation, fresh database migrations, type checking, lint, build, and the test suite on Node 22.13 and Node 24. Local two-browser checks also exercise collaboration and editable export. These checks do not establish exhaustive PDF-editor compatibility or production security.

## Start locally

Use Node.js 22.13 or newer:

```sh
npm ci
npm run db:migrate:local
npm run dev
```

Upload `examples/markroom-sample.pdf` and follow the [README](../../README.md). Local development needs no Cloudflare account. Hosting requires your own resources and configuration.

## Release boundaries

- Anyone with a room link can read its PDF, reviewer names, and comments. Closing a room freezes edits; it does not revoke access or delete data.
- There is no account recovery, global rate limit, automatic expiry, room-deletion UI, or managed backup service. Public hosting needs an operator plan for these.
- Stamps, signatures, attachments, redaction, and form editing are disabled. Supported annotations still need broader cross-reader testing.
- The October 3, 2026 dependency audit records 28 affected package entries. Review the [dependency assessment](../dependency-review.md); passing CI does not resolve those findings.
- Native PDFium attribution remains incomplete. This source preview omits generated viewer binaries. Official prebuilt releases and public browser deployments remain gated on the exact native-library/font manifest and required notices. See [third-party notices](../../THIRD_PARTY_NOTICES.md).
